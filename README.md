# ЭПОХИ — Летопись империй

Пошаговая 4X-стратегия для смартфонов и ПК. Вдохновлена классикой жанра (Civilization II и её наследники), но это **оригинальная игра** со своими правилами, графикой и названием. Не клон.

**Статус:** играбельный прототип 0.1. Партия от основания столицы до победы, 8 наций, 32 технологии, ИИ, события, сохранения, управление пальцем и мышью.

## Быстрый старт

```bash
npm install
npm run build      # → dist/index.html (вся игра в одном файле, ~220 КБ)
```

Откройте `dist/index.html` в браузере на ПК. Чтобы играть с телефона в той же Wi-Fi-сети:

```bash
npm run dev        # сборка при изменениях + сервер на http://<IP-компьютера>:5173
```

Проверки:

```bash
npm run typecheck          # типы TypeScript
npm run sim -- 3 250       # 3 партии ИИ против ИИ по 250 ходов, проверка инвариантов и статистика
node tools/smoke.cjs       # браузерный тест: телефон (iPhone 13) и ПК, 25 ходов, скриншоты в dist/shots
```

## Структура

```
src/
  core/        чистые правила без DOM — работают и в браузере, и на сервере
    data.ts      таблицы: рельеф, ресурсы, юниты, нации, здания, технологии, хартии
    rules.ts     расчёты: доходность, стоимость, сила, очки
    world.ts     движение, бой, города, видимость, дипломатия, конец хода
    ai.ts        ИИ соперников
    mapgen.ts    генерация карты
    events.ts    «Летопись» — события с выбором
    turn.ts      порядок хода и победа
    setup.ts     новая партия, Испытание дня
  ui/          интерфейс
    app.ts       контроллер: ввод, камера, действия, сохранения
    render.ts    отрисовка карты на Canvas
    panels.ts    HUD, карточки, город, технологии, дипломатия
    screens.ts   меню, новая игра, лавка, помощь, итоги
    icons.ts     векторные иконки (SVG + Canvas)
    styles.css   стили, адаптив телефон/планшет/ПК
tools/
  sim.ts       headless-симуляция
  smoke.cjs    браузерный тест
build.mjs      сборка в один HTML (+ dist/artifact.html для публикации)
```

## Упаковка в приложения (следующий шаг)

- **Android / iOS:** Capacitor — `npx cap init`, `webDir: dist`, затем `npx cap add android`.
- **Windows / Mac / Linux (Steam):** Tauri или Electron, загружающие `dist/index.html`.
